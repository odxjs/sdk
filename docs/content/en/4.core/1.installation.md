`@odxjs/core` is a framework-agnostic package. Use it when you need standard OData TypeScript interfaces or the lightweight `$odata` fetch client outside of a Nuxt application.

::warning
ODX packages are not yet available from npm. The registry commands below describe
the intended public workflow and must not be expected to resolve until a
versioned prerelease has been published.
::

:::steps{level="2"}

## Install the Package

:::code-group
```bash [pnpm]
pnpm add @odxjs/core
```
```bash [npm]
npm install @odxjs/core
```
```bash [yarn]
yarn add @odxjs/core
```
:::

## Import Types

Use the shared OData types in any TypeScript project.

```ts
import type { ODataQuery, ODataResponse } from '@odxjs/core'

const query: ODataQuery = {
  $select: ['ProductID', 'ProductName'],
  $filter: 'UnitPrice gt 20',
  $top: 10
}
```

## Use the `$odata` Client

The `$odata` client is a lightweight, promise-based HTTP client for OData services.

```ts
import { $odata } from '@odxjs/core'

const products = await $odata('https://services.odata.org/V2/Northwind/Northwind.svc/')
  .entitySet('Products')
  .list({ $top: 5 })
```

:::

## When to Use Core Directly

| Situation | Recommended Package |
| --- | --- |
| Building a Nuxt 4 application | [`@odxjs/nuxt`](/nuxt/getting-started) |
| Building a BFF proxy layer | [`@odxjs/proxy`](/proxy/installation) |
| Writing shared OData types or utilities | `@odxjs/core` |
| Integrating OData in a React/Plain Node app | `@odxjs/core` |
