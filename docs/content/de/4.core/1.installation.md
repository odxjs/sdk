`@odxjs/core` ist ein Framework-agnostisches Paket. Verwenden Sie es, wenn Sie Standard-OData-TypeScript-Interfaces oder den leichtgewichtigen `$odata` Fetch-Client außerhalb einer Nuxt-Anwendung benötigen.

::warning
Noch kein ODX-Paket ist über npm verfügbar. Die folgenden Registry-Befehle
beschreiben den vorgesehenen öffentlichen Ablauf und funktionieren erst, wenn
ein versioniertes Prerelease veröffentlicht wurde.
::

:::steps{level="2"}

## Paket installieren

:::code-group
```bash [pnpm]
pnpm add @odxjs/core
```
```bash [npm]
npm install @odxjs/core
```
```bash [yarn]
yarn add @odxjs/core
```
:::

## Typen importieren

Verwenden Sie die gemeinsam genutzten OData-Typen in jedem TypeScript-Projekt.

```ts
import type { ODataQuery, ODataResponse } from '@odxjs/core'

const query: ODataQuery = {
  $select: ['ProductID', 'ProductName'],
  $filter: 'UnitPrice gt 20',
  $top: 10
}
```

## Den `$odata` Client verwenden

Der `$odata` Client ist ein leichtgewichtiger, Promise-basierter HTTP-Client für OData-Services.

```ts
import { $odata } from '@odxjs/core'

const products = await $odata('https://services.odata.org/V2/Northwind/Northwind.svc/')
  .entitySet('Products')
  .list({ $top: 5 })
```

:::

## Wann Core direkt verwendet werden sollte

| Situation | Empfohlenes Paket |
| --- | --- |
| Erstellung einer Nuxt 4 Anwendung | [`@odxjs/nuxt`](/de/nuxt/getting-started) |
| Erstellung einer BFF-Proxy-Schicht | [`@odxjs/proxy`](/de/proxy/installation) |
| Schreiben von geteilten OData-Typen oder Utilities | `@odxjs/core` |
| Integration von OData in eine React/Plain Node App | `@odxjs/core` |
